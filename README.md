# Portfolio - Koffi Levis AKALETE

Mon portfolio personnel développé avec Angular.

## Stack

- Angular 22
- GitHub Actions (CI/CD)
- GitHub Pages

## Utilisation

```bash
# Installer les dépendances
npm install

# Lancer en développement
ng serve

# Build production
ng build --configuration=production
```

## Déploiement

Le site est automatiquement déployé sur [GitHub Pages](https://akaletekoffilevis.github.io/mon-portfolio/) à chaque push sur `main`.
